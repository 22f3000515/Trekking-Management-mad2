# Trekking Management Application V2

## Modern Application Development II (MAD-II) Project

### Project Description
The Trekking Management Application V2 is a full-stack web application developed as part of the Modern Application Development II course. It allows users to browse and book trekking packages, while administrators can manage treks, users, bookings, and other application functionalities.

### Technologies Used
- Flask (Backend REST API)
- Vue.js (Frontend)
- SQLite (Database)
- Redis (Caching)
- Celery (Background Jobs)
